# Perséphone

Station scientifique Perséphone, orbite martienne, 2091. Un jeu d'enquête pour 2 à 4 joueurs : un écran commun (ordinateur ou télévision) et un ou deux téléphones.

Jouer : https://theovoneuw-cell.github.io/persephone/

Projet du cours de création sonore et mixage, 3e année, Studio M. Le son du jeu est créé par les étudiants.
